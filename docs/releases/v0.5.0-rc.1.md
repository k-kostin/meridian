# v0.5.0-rc.1 Commercial Pilot Readiness

Date: 2026-07-27

## Included

- Local SQLite backup/restore and migration-aware automatic backup retention.
- Creator, updater and poster attribution for core warehouse documents.
- Pilot-grade operational activity for posting, imports, backup, demo reset and reference changes.
- Explicit Local Single User deployment boundary.
- Transactional Excel imports with safe retry behavior.
- Backdated stock timeline validation.
- Formula-injection protection for every Excel export.
- Locked Electron build inputs, per-install secret and fresh-profile desktop smoke coverage.
- Minimal GitHub verification workflow.

## Version

- Django/UI: `v0.5.0-rc.1`.
- Electron package: `0.5.0-rc.1`.

## Why This Is a Prerelease

Synthetic import workbooks are covered, but real client Excel files have not yet passed acceptance. The final `v0.5.0` tag must wait for that evidence.

Windows packaging is tracked separately as Stage D / `v0.6.0`; this release candidate does not claim a validated NSIS installer.
