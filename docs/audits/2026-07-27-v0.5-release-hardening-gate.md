# v0.5 Release Hardening Gate

Date: 2026-07-27

## Verdict

The automated Stage C code gate is ready for `v0.5.0-rc.1`.

This is not a final Windows desktop release. The prerelease marker stays until real client Excel files are accepted. Windows installer validation belongs to Stage D / `v0.6.0`.

## Closed Risks

- Backdated issue and transfer documents cannot create a negative daily closing balance later in the timeline.
- Item and opening-inventory imports commit data and required operational activity atomically.
- Imported inventories and generated adjustments preserve authenticated-user attribution.
- Local Electron sessions use an explicit loopback-only trusted profile; ordinary production anonymous users remain read-only.
- Electron uses a stable per-install Django secret stored outside bundled resources.
- Automatic backup runs only before real migrations of an existing database and retains five automatic copies without pruning manual backups.
- Electron dependencies are locked, Windows build uses `npm ci`, and PyInstaller uses onedir without UPX.
- Formula-like spreadsheet text is exported as inert text while dates and numeric quantities keep their native cell types.
- GitHub Actions independently runs the code-level verifier stack.

## Automated Evidence

- Django system check.
- Full Django test suite.
- Public repository readiness check.
- Electron JavaScript syntax and packaging contract.
- Fresh-profile sidecar flow: first references, receipt, posting, balances, Excel export, manual backup and restart.
- Migration lifecycle smoke: one pre-migration copy before upgrade and no copy on a current-schema restart.

## Open Acceptance Gates

### Final v0.5.0

- Validate at least 2-3 genuine client workbook structures.
- Record evidence-based alias or mapping gaps.
- Confirm no duplicate or destructive update behavior.

### Stage D / v0.6.0

- Build the PyInstaller sidecar and Electron NSIS installer on real Windows.
- Install without administrator rights.
- Verify offline first launch, first operation, shutdown, relaunch, SQLite persistence and Excel downloads.
- Check Defender/EDR behavior for the unsigned onedir sidecar.
- Repeat `npm audit`; electron-builder still reports transitive build-time advisories even after direct dependencies were upgraded.

## Release Boundary

No Windows binary is published by this gate. Code signing, auto-update and installer reliability are not claimed complete.
